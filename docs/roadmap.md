# Roadmap

These are contribution opportunities, not promised delivery dates. Propose a
focused implementation in an issue before taking on a substantial change.

## Make releases dependable

- Exercise packaged builds on more Debian, Ubuntu, and Arch installations.
- Expand architecture coverage once each target has build and launch validation.
- Improve distribution integration and explore AUR submission with a maintainer.
- Keep the bundled runtime and dependency updates reproducible and documented.

## Make the quiz worth returning to

- Save personal records and a small session history.
- Add an optional revision mode based on previously missed answers.
- Explore a deterministic daily challenge and graduated difficulty.
- Offer focused quizzes from a Pokédex family or a saved card collection.

## Welcome more players and contributors

- Review French/English wording and improve translated upstream metadata coverage.
- Refine narrow-terminal layouts, keyboard focus, and accessible colour choices.
- Exercise catalogue updates and first-run recovery on more network conditions.
- Expand meaningful tests around save migrations, catalogue failures, and UI navigation.

Current functionality is described in [the playing guide](usage.md); planned
work should not be confused with features already available.
